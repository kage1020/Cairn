## 15.1 実装時に決めること

**来歴 (provenance) をどこに置くか。** `.crn` のヘッダか、ロックか。これは決まりました。`.crn` が持つのは、ヒントである `@intended_targets` と、書いたときの言語のバージョンを示す `@cairn` だけで、`verified` のような記録はコンパイラがロックに書きます ([バージョンとエディション §10.6](/ja/spec/versioning-editions/#106-来歴-provenance-とロック))。

**座標系。** 角を原点とし `front = +z` とする今の規約を続けるか、中心を原点にする、入口を基準に向きを決める、といった仕組みに移るか。これは決まりました。配置の原点は、軒の出の列を含めた広がりの `x` と `z` が小さい側の角で、構造ファイルはこの点を `(0, 0, 0)` として書きます ([コンポーネント・編集・複数建築 §9.3.2](/ja/spec/components-editing-sites/#932-原点セレクタ))。一方、`struct` や `def` の本体のメンバー行に書く座標は、`size=` の敷地の `x` と `z` が小さい側の角から測り、ほかのメンバーと同じく `overhang=` の分だけずれます ([コンパイルモデル §4.3](/ja/spec/compilation/#43-切妻屋根のボクセル規則))。そうした行の座標の組 (`from=1,1,1`、`at=4,3,2`) も、仕様が定めた時点で同じように読みます。`y` は床から上へ増え、`front` / `back` / `left` / `right` はそれぞれ `+z` / `-z` / `-x` / `+x` を向きます ([構文 §5.4](/ja/spec/syntax/#54-セレクタ)、[§9.3.1](/ja/spec/components-editing-sites/#931-座標規約))。中心を原点にすると、辺の長さが偶数のときは原点が本当の中心からずれ、作者はその寄せ方を覚えていなければなりません。`at=center` が偶数の壁で中点の右側の列を選ぶのと同じです。入口を基準にした座標系を足しても得るものはありません。どの壁を `front` にするかは作者が選び、入口の壁はドアの `side=` がすでに指しています。ワールドでどちらを向くかは、プレイヤーがゲームで構造ファイルを置くときに決まり、`place` には回転がありません。そのため、座標系を固定しても向きは固定されません。階ごとにローカルな `y=0` は `level y=N` が提供します ([コンパイルモデル §4.7](/ja/spec/compilation/#47-level-によるまとまりと体積の導出))。

**逆変換で使う IR の型。** 情報の一部を欠いた状態も表せる単一の IR にするか、Intent IR と Raw Geometry IR を別の型にするか。暫定の方針は、「block-array の層は共有し、その上のメンバーの層で型を分ける」です ([アーキテクチャ](/ja/spec/architecture/))。

**旧形式の `.schematic`** (1.13 より前) は、v1 では扱いません。数値 ID の対応付けは、将来オプションとして検討する余地があります。

**言語の進化の方針。** Rust のような年単位のオプトインの仕組みにするか、リリースごとに変更を告知するか。これは決まりました。リリースごとに告知します。その扱いは [互換性ティア §C.3](/ja/spec/compatibility/#c3-破壊的変更の告知方法) に記しています。リリースが壊してよい範囲はすでにティアで決まっており、Stable な面を壊すときは `W_DEPRECATED` の猶予期間を置くので、ファイルは少なくとも 1 リリースのあいだに移行できます。オプトインを足すと、範囲を決める仕組みが 2 つになり、過去の改訂の規則をすべてコンパイラの中に生かしておくことになります。また、「エディション」はすでに Java / Bedrock を指しており、`@cairn` は来歴の記録のままです。

## 15.2 まだ検討していない話題

**プリミティブへの昇格。** 柱やアーチなどを意味プリミティブに昇格させるか。判断は [評価フレームワーク](/ja/spec/evaluation/) の実験データに基づいて行います。

**内装。** `inside.front` という接頭辞で足りるのか、より上位の `room` という概念が必要なのか。また、家具を `def` のライブラリでまかなえるのか。
