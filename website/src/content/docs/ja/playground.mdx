## このページで最終的にできること

すべてブラウザ内で完結する、2 ペイン構成の Cairn の作業台になる予定です。

- 左側に `.crn` エディタ。シンタックスハイライトと、Cairn LSP による診断をその場で表示します。
- ターゲットの選択 (`--edition java|bedrock`、`--target <version>`) とコンパイルボタン。
- 右側のペインは、次の表示を切り替えられます。
  - **Resolved IR**: フェーズ評価を終えた block-array IR。
  - **Diagnostics**: `cairn` や LSP と同じ「何が誤りか / 有効な候補 / 推奨する修正」の形の lint 出力 ([Lint](/ja/spec/lint/))。
  - **Bytes**: コンパイラがエディションごとに出力する NBT / schematic のバイト列。

[エコシステム連携](/ja/spec/ecosystem-interop/)で説明する引き上げのループも、ここで使えるようにします。`.litematic` や `.mcstructure` のファイルをドロップすると、コンパイラが raw 主体の `.crn` と、元データとのボクセル差分を表示します。

## それまでの間に読めるサンプル

```text
@cairn 2026.06
@requires version>=1.20

theme medieval:
  slot floor -> @oak_planks
  slot wall  -> @cobblestone
  slot roof  -> @spruce_stairs

struct cottage size=9x7
  floor  mat_slot=floor
  walls  class=outer mat_slot=wall height=4
  door   side=front at=center
  window class=small side=front offset=2 y=2 size=2x2 sym=true
  roof   kind=gable mat_slot=roof overhang=1
```

進捗は [Cairn の GitHub リポジトリ](https://github.com/kage1020/Cairn)で確認できます。`cairn-lang-wasm` が `compile()` のバインディングを公開したら、すぐにプレイグラウンドを使えるようにします。
