Cairn は Minecraft 建築物のための記述言語です。意図 — 壁、屋根、窓、対称性、テーマ、レッドストーン
論理 — を宣言すると、コンパイラがボクセルを解決します。ブロックステート、向き、座標計算、信号配線、
そしてビルド対象のエディションとバージョンに応じた正しいブロック ID です。

ケルン (cairn) とは、場所を示すために意図的に積み上げられた石のことです。Minecraft の建築物はまさに
それです。名前がそのままテーゼになっています。

## 何を解決するか

Minecraft の NBT/SNBT は AI が読み書きするには非効率です。バイナリであり、1 ブロック 1 レコードだか
らです。粒度も噛み合っていません。人も AI も壁・屋根・対称性で建築を考えます。Cairn は、AI が持つ汎
用的な建築知識と Minecraft のボクセル世界の間に立ちます。

可搬な成果物は常に Cairn ソースです。出力された NBT や schematic はターゲットに固定されたビルド成果
物、つまりコンパイル済みバイナリに相当します。新しい Minecraft バージョンを狙うときは、NBT を変換す
るのではなく **ソースを再コンパイル** します。

## あえてやらないこと

**NBT との完全なラウンドトリップ忠実度。** generation-first は設計上 lossy です。取り込んだ
schematic は忠実な低レベルの写し取りとして保持し、LLM が慣用的な Cairn にリフトします。voxel-diff の
ループが収束を駆動します。

**任意の状態機械や CPU のレッドストーン一般順序合成。** v1 は組み合わせゲートと厳選したマクロライブ
ラリのみで、それ以外は物理配置か `raw` エスケープハッチに落とします。

**1.13 以前の数値 ID `.schematic` のインポート。** v1 はフラット化に未対応です。

正規の表現は [目的とスコープ](/ja/spec/overview/) を参照してください。

## ステータス

Cairn は設計段階、ドラフト `2026.06` です。言語仕様はオープンに設計中で、リファレンスコンパイラはま
だスケルトンです。したがって現時点で最も価値のあるコントリビュートは、設計への批判、具体的な提案、実
用例です。詳細は [`CONTRIBUTING.md`](https://github.com/kage1020/Cairn/blob/main/CONTRIBUTING.md) を
参照してください。
