Edit the source below and it compiles as you type: the same compiler as the `cairn` CLI, built to
WebAssembly from [`cairn-lang-wasm`](https://github.com/kage1020/Cairn/tree/main/crates/cairn-lang-wasm)
and run in your browser, so nothing you write leaves the page. Each build is
`cairn compile --edition <edition> --target <target>`, with the built-in registry packs.

<Playground lang="en" />

## What the page shows

- **Findings** are the ones `cairn check` and `cairn compile` report, in the shape
  [Lint](/spec/lint/) gives them: what is wrong, what would be valid, and how to fix it. Select
  one to put the cursor where it points. A refusal of the whole run, such as a `--target` the
  edition does not ship or one a `@requires` floor rules out, is listed with them.
- **Result** draws the [block-array IR](/spec/architecture/) the structure files are written
  from, layer by layer, with the palette its cells index into. It appears whenever no finding is an
  error, even when the run itself is refused.
- **Structure files** are the `.nbt` (Java) or `.mcstructure` (Bedrock) files `cairn compile`
  would write, one per structure. The lockfile is not written here: it records a build on disk, and
  this one is never saved.
