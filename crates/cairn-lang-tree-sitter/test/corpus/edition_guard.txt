==================
A guard naming no edition is rejected
:error
==================

struct s size=3x3
  @edition pocket
    raw_block mat=minecraft:stone at=1,0,1

---

==================
A guard with nothing indented under it is rejected
:error
==================

struct s size=3x3
  @edition java
  raw_block mat=minecraft:stone at=1,0,1

---

==================
A guard inside a guard is rejected
:error
==================

struct s size=3x3
  @edition java
    @edition bedrock
      raw_block mat=minecraft:stone at=1,0,1

---

==================
A guard at top level is rejected
:error
==================

@edition java
struct s size=3x3
  floor mat_slot=f

---

==================
A one-line braced guard is rejected
:error
==================

struct s size=3x3
  @edition java { raw_block mat=minecraft:stone at=1,0,1 }
