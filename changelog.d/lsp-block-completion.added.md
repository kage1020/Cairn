- *(lsp)* An `@` token completes from every canonical id a built-in pack's blocks table declares,
  Java's and Bedrock's, the vocabulary `E_UNKNOWN_ID` answers from, so `@cherry_planks` and
  `@stonebrick` are offered as well as the ids the materials catalogs map to. Each id's detail
  names the editions and versions that declare it, such as `java 1.21.4, 26.3; bedrock 1.21.60,
  1.26.60` for `pale_oak_planks`. The catalogs' abstract tokens are offered first. Only the tokens
  matching what is typed are offered, at most 100, and an answer cut there is marked incomplete so
  the editor asks again as the token grows.
