- *(lsp)* `textDocument/hover` is answered. A top-level item's or a member's keyword, and the key
  of a `key=`, show their entry in the keyword reference with the section that specifies them. A
  `@` token in a theme's `slot` row or a `connect`'s `path=` shows what binds it and the block it
  names on Java and on Bedrock. A member's line shows its `id=`, the `intent_state` it writes and
  the `resolved_state` each place it is built in holds on each edition, as `cairn lower --edition`
  resolves it.
- *(spec)* `spec/syntax` gains "Keyword reference": every item and member keyword, and every
  `key=` each member accepts, in one line with the section that specifies it, in English and
  Japanese. `cairn docs spec/syntax` prints an entry by its name, such as `` "`door`" ``.
