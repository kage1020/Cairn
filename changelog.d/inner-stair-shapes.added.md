- *(core)* An eave `stair` takes `shape=inner_left` and `shape=inner_right` beside `straight`,
  `outer_left` and `outer_right`, so it can name any of a stair's five shapes. Java writes the
  shape as named; a Bedrock version with no stair `shape` state drops it with `W_INTENT_DEGRADED`,
  as it drops an outer corner, and 1.26.60 writes it as `minecraft:corner`.
